<b>Challenge from Frontend Mentor</b>
<b>Small Portfolio</b>
<p>
This is a simple portfolio web page built using HTML and CSS.</p>
<b>
Project Description</b>
<p>
This project showcases a small, centered portfolio layout with a profile image, location, description, and social media links.</p>
<b>
Features</b>
<p>
<p>Responsive design using media queries</p>

<p>Profile image with circular style</p>

<p>Address text highlighted using rgb(187, 255, 0)</p>

<p>Five social links: GitHub, FrontEnd Mentor, LinkedIn, Twitter, Instagram</p>

<p>Links styled using Flexbox in a vertical column</p>

<p>Interactive links with hover and focus effects</p>

<p>Font used: Inter, use from public/fonts</p>

<p>Container background color: hsl(0, 0%, 12%)</p>

<p>Body background color: hsl(0, 0%, 8%)</p>

<b>Notes</b>

<p>The :focus state of the links uses the same green color (rgb(187, 255, 0)) as the address.</p>

<p>Responsive behavior is handled for screen widths above 375px.</p>

<p>Smooth transitions are applied on :hover and :focus for better UX.</p>
